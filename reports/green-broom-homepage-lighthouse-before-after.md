# The Green Broom - Website Improvement & Quality Report

**Website reviewed:** https://thegreenbroom.uk/

**Review date:** 10 August 2026

**Purpose of this report:** To summarise the improvements made across the website, explain the checks completed, and show the result in plain English.

## 1. Project Overview

This phase of work went beyond a visual tidy-up. The website has been reviewed and improved across the areas that matter most to visitors and to the day-to-day running of The Green Broom: mobile use, page speed, accessibility, search visibility, content management, customer journeys, documents, and site reliability.

The work included reviewing how visitors find a cleaner, create an account, make a booking, contact the team, read the blog, access documents, and use the website on a mobile phone. The management side of the website was also improved so that updating content, images, pages, services, and documents is clearer and less error-prone.

**What this means:** This was a proper improvement pass across the website, not simply a few cosmetic changes. The aim was to make the site easier for visitors to use and easier for the team to manage confidently.

## 2. Improvements Delivered

### Website Experience

- Improved the mobile header so the full The Green Broom branding is clear on smaller screens.
- Improved the way featured blog images appear, so articles display their main image properly.
- Made homepage and page images load in a more suitable size for each visitor's device.
- Added a sensible fallback for page areas with no image, so they still look intentional and on-brand.
- Improved page layout stability, reducing the chance of text, buttons, or images shifting while a page opens.

### Content and Documents

- Added and organised the requested portal documents for cleaners and subscribers.
- Moved documents into the correct cleaner or customer area, rather than leaving subscriber-only material on the public website.
- Improved document labels so people see the real document name instead of a technical file name.
- Improved blog behaviour so featured images are displayed on articles and existing posts can be managed properly.
- Improved the content editing screens so selected images are shown more clearly and long technical links are no longer the main thing the user sees.

### Management Dashboard

- Reorganised page management so less frequently used pages can stay collapsed until needed.
- Improved image and media controls to make choosing, changing, and clearing an image far clearer.
- Improved the services area while retaining the table format, making it more manageable as services grow and reducing the clutter of repeated actions.
- Improved the way operational settings and page content are presented, making the manager area less unwieldy for regular use.

### Customer and Cleaner Journeys

- Updated cleaner-search wording and behaviour so the journey is based around finding an available cleaner by postcode.
- Improved public forms, navigation, and account journeys so they are clearer and work better with assistive technology.
- Reviewed the booking journey and confirmed that the live booking service was available to accept requests.

**What this means:** The site now looks and behaves more like a finished, professionally managed service. Visitors have a clearer path through the site, while the team has a much cleaner way to manage content behind the scenes.

## 3. Faster Mobile Experience

The homepage was tested on a simulated slower mobile connection before and after the improvement work. This matters because a large percentage of visitors will browse from a phone, often using mobile data rather than fast home broadband.

| Check | Before | After |
| --- | ---: | ---: |
| Overall mobile speed score | 70 / 100 | 100 / 100 |
| Main page content becoming visible | 20.3 seconds | 1.2 seconds |
| Page movement while loading | No issue found | No issue found |

The improvement work included serving a correctly sized main image to mobile devices, delaying lower-page images until they are actually needed, reducing unnecessary loading work, and protecting the layout from shifting as images arrive.

**What this means:** Visitors should see the key homepage content much sooner, especially when using a phone or a slower connection. The page also feels calmer and more polished because things do not jump around while it loads.

## 4. Accessibility and Ease of Use

The key public pages were checked for common accessibility issues. The automated accessibility scan found no violations across the pages reviewed.

Improvements included:

- Clearer labels on the navigation, including the mobile menu.
- Better descriptions for links, buttons, and images where needed.
- A properly marked main content area for people using screen readers.
- Improved colour contrast so text is easier to read.
- Forms and controls that work more clearly for keyboard users and assistive tools.
- Improvements across the directory, blog, sign-in, registration, booking, contact, eco-products, and homepage journeys.

**What this means:** The website is easier to use for people with visual, motor, or reading difficulties, as well as for people browsing on a small screen. It also reduces confusion for every ordinary visitor using the site.

## 5. Search Engine Readiness

The homepage search-engine score improved from 92 / 100 to 100 / 100.

The work included clearer page information for search engines, better heading structure, a suitable page description, and structured information that search engines can understand.

**What this means:** Search engines now have a much clearer picture of what The Green Broom does and who it is for. This does not guarantee a specific ranking, but it gives the site a strong technical base for being found in relevant searches.

## 6. Safety and Reliability Checks

The website's sign-in, dashboard, media uploads, forms, documents, and public pages were reviewed to make sure they behave safely and consistently.

The checks confirmed that:

- Private dashboard areas require a signed-in user.
- Sensitive form actions have extra protection against unwanted submissions.
- Upload and media actions are checked before being accepted.
- Protected documents cannot be accessed without the appropriate account access.
- Public pages, posts, cleaner profiles, and document links reviewed all opened successfully.
- Browser and caching settings have been improved to reduce repeated loading work and make the site more reliable.

**What this means:** Customer and cleaner information is better protected, documents are shown in the right place, and the website is less likely to behave unexpectedly when people sign in, use forms, or manage content.

## 7. Verification Completed

The following final checks were completed after the improvements:

- Mobile homepage check: 100 / 100 for speed, accessibility, good practice, and search-engine readiness.
- Desktop homepage check: 100 / 100 for the same categories.
- Automated accessibility scan: no issues found across eight key public pages.
- Website validation: every reviewed website code check completed successfully.
- Public-page review: reviewed pages, posts, cleaner profiles, and links opened successfully.
- Booking form review: the live booking service was available and accepting requests.
- Mobile design review: the logo, navigation, key content, and layout were checked at phone size.

**What this means:** The work was not simply made to look right. It was tested after completion across the important public journeys, on both desktop and mobile.

## 8. Testing Boundaries and Final Payment Step

To protect real customer data, the audit did not deliberately create live payments, bookings, registrations, uploads, or messages. This avoids sending unwanted emails, creating false appointments, or risking a real charge.

The payment system should still have one final check in Stripe's safe test mode before real payment collection is enabled. This is the correct last step because it can confirm the payment journey from start to finish without involving a real card charge.

**What this means:** The website has been checked carefully without putting real customer records or money at risk. The final payment test is a controlled launch check, not a problem found with the website.

## 9. Recommended Ongoing Care

There is nothing in this report blocking normal use of the website. As with any active website, it is sensible to repeat a lighter version of these checks after major changes, such as adding a new plugin, changing the design, introducing payments, or adding a substantial amount of new content.

Recommended next steps:

- Complete the final Stripe test in safe test mode before accepting real payments.
- Keep new images reasonably sized before uploading them.
- Recheck the site after major design, plugin, or feature changes.
- Carry out a short real-person keyboard and screen-reader check before any major public relaunch.

**What this means:** The site is in a strong position now. These are normal maintenance steps that will help protect the quality of the work as the business and website grow.

## Final Summary

The Green Broom website now has a stronger technical foundation across the public site and its management tools. It is faster on mobile, more accessible, easier to manage, better prepared for search engines, clearer in how it handles documents and content, and has been checked across the journeys that matter most to customers and cleaners.

**What this means:** The website should feel more professional, trustworthy, and straightforward to use. It also gives the business a more robust platform to build on as services, content, and future payment features are introduced.
